# Node-Link Analysis Notes

## Minimum Schema
- Node: unique id, label, type, status, and source references
- Edge: source node, target node, relationship type, direction, confidence, and evidence references
- Event links: when useful, treat events as their own nodes instead of forcing everything into person-to-person edges

## Analytical Questions
- Which nodes are central, bridging, or isolated?
- Which links are inferred rather than observed?
- Which missing links would change the interpretation of the network?

## Seed Concepts From Existing Repo Notes
- Argument mapping helps separate claim structure from relationship structure.
- ACH can be used to test rival interpretations of the same network.
- Geovisualization can be layered onto node-link work when location materially affects interpretation.
