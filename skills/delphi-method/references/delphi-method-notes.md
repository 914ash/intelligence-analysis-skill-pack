# Delphi Method Notes

## Use Cases
Use Delphi when the problem is complex, evidence is fragmented, and expert judgment needs to be elicited in a disciplined way.

## Core Mechanics
- Define the intelligence question, panel criteria, round count, and stopping rule before starting.
- Keep responses anonymous to reduce dominance and groupthink effects.
- After each round, provide controlled feedback: summary statistics, anonymized rationales, and unresolved disagreement.
- Stop when the preset convergence threshold is met or when the study reaches the maximum number of rounds.

## Variants
- Classical Delphi: several sequential rounds with structured feedback.
- Modified Delphi: fewer rounds and more steering up front.
- Real-time Delphi: continuous updates with immediate aggregation.

## Output Expectations
Record the consensus level, the main dissenting view, confidence, and the evidence or assumptions driving disagreement.
