# Analytical Contract

Apply this contract in every intelligence skill unless the task is purely routing.

## Required Output Elements
- Restate the intelligence question and scope.
- Separate fact, inference, assumption, and gap.
- Evaluate source quality before leaning on a claim.
- Compare the leading explanation to at least one credible alternative.
- State confidence and the main caveat.
- Recommend the next collection or analytic step when uncertainty remains.
- For autonomous execution, record assumptions and missing inputs instead of asking the user follow-up questions.

## Definitions
- Fact: directly reported or observed information accepted for working use.
- Inference: analyst interpretation drawn from facts.
- Assumption: condition treated as true because evidence is missing or incomplete.
- Gap: missing information that materially limits confidence or changes options.
