# Templates

Use these as starter shapes, not as rigid forms. Pick the smallest template that preserves traceability and consumer usefulness.

## Topic Triage Card

| Field | Prompt |
| --- | --- |
| Mission area | What broad problem space are we in? |
| Candidate topic | What discrete issue might be worth analysis? |
| Decision value | Who would use the answer and what could change? |
| Time horizon | Why now? |
| Evidence path | What signals or sources could realistically answer it? |
| Next skill | Usually `craft-intelligence-question` or `research-and-collection` |

## Long Memo Template

```md
# [Analytic title]

## BLUF
[Main judgment]. [Why it matters]. [Confidence and main caveat].

## Key Judgments
- [Judgment 1]
- [Judgment 2]
- [Judgment 3]

## Analysis
[Short lead paragraph]

## Alternatives
We considered the alternative that [alternative explanation]. [Why it does not currently lead or what would elevate it].

## Gaps And Watch Items
- [Gap or watch item]
- [Gap or watch item]

## Method Note
[Evidence base, technique used, and major limitations]
```
