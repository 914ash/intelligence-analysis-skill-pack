# Evidence Ledger Template

Use a simple row structure when gathering or transforming evidence.

| Field | Purpose |
| --- | --- |
| Item ID | Stable identifier for later reference |
| Source | Where the information came from |
| Date | When the information was published or observed |
| Claim / Observation | The factual content |
| Type | Fact, claim, inference, assumption, or gap |
| Reliability | Working assessment of the source |
| Credibility | Working assessment of the claim |
| Corroboration | None, partial, or strong |
| Relevance | Why it matters to the question |
| Notes | Caveats, contradictions, or follow-up |
