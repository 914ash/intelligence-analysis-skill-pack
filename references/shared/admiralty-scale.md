# Admiralty Scale Quick Reference

Use this reference when a skill needs a compact way to express source reliability and information credibility.

## Source Reliability
- `A`: Completely reliable
- `B`: Usually reliable
- `C`: Fairly reliable
- `D`: Not usually reliable
- `E`: Unreliable
- `F`: Reliability cannot be judged

## Information Credibility
- `1`: Confirmed by other independent sources
- `2`: Probably true
- `3`: Possibly true
- `4`: Doubtfully true
- `5`: Improbable
- `6`: Truth cannot be judged

## Usage Rules
- Reliability and credibility are separate judgments. A reliable source can still provide a weak claim.
- Do not assign a grade without a short reason.
- Prefer explicit uncertainty over false precision when the source basis is thin.
- Revisit the grade when corroboration changes.

## Example Notation
- `B2`: Usually reliable source; claim is probably true.
- `C4`: Fairly reliable source; claim is doubtfully true.
- `F6`: Source and claim both remain too uncertain for confident use.
